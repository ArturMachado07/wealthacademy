# Imagens reais da Wealth Academy

Coloque aqui as fotografias reais, com estes nomes exactos (extensão .jpg, .jpeg, .png ou .webp — só uma por nome):

- `hero.jpg` — imagem de fundo do Hero da homepage (formação/participantes)
- `sobre.jpg` — imagem institucional/comunidade na página Sobre Nós
- `empresas.jpg` — imagem de contexto corporativo na página Para Empresas

Assim que o ficheiro existir com o nome certo, o site passa a mostrá-lo automaticamente — não é preciso mexer no código. Enquanto não existir, aparece um painel gráfico discreto (nunca uma fotografia de banco de imagens genérica).
